Hybrid Inference Routing Architecture

1. Request Ingestion

User types or speaks Hindi/English text. The client parser evaluates token length, language pair, and live network status (`navigator.onLine`).

2. Local Edge Router (Nano)

If offline or ≤15 words: Executed locally via Chrome Built-in AI (Gemini Nano) / local inference engine. Zero cloud egress, 100% privacy, ~16ms latency.

3. Cloud Scaler (Gemini 1.5)

If online and complex (>15 words or multi-paragraph): Routes to Google Gemini API via Firebase AI Logic for nuanced context, idiom translation, and accuracy.
